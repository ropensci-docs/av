# Logging

Get or set the [log
level](https://www.ffmpeg.org/doxygen/4.0/group__lavu__log__constants.html).

## Usage

``` r
av_log_level(set = NULL)
```

## Arguments

- set:

  new [log
  level](https://www.ffmpeg.org/doxygen/4.0/group__lavu__log__constants.html)
  value
